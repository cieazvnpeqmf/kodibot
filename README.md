## 🤖 Overview

KodiBot integrates a conversational AI assistant directly into Kodi, letting you search media, control playback, and get recommendations using natural language.

Whether you're a newcomer or a veteran, KodiBot provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
